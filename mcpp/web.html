Each run starts cmd /c in a fresh WebAssembly instance. Files under \work
      persist between runs; environment variables do not. There is no interactive console, since a page cannot
      block while it waits for a key, so pause and set /p read end of file.
      Press Ctrl+Enter to run the script.

    
Built with mcpp for wasm32-emscripten:
      mcpp pack cmd.exe --profile web --target wasm32-emscripten --pkg-format web.
      The same sources also build for Linux, Windows, macOS, FreeBSD, Android,
      openkal images, UEFI and DOS
      (README).
